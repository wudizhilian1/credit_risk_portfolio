# 数据清洗工具学习笔记

## 一、核心数据清洗工具基本概念

### 1. OpenRefine（可视化数据清洗工具）

- **核心定位**：开源的可视化数据清洗工具（原 Google Refine），主打「探索性数据分析 + 交互式清洗」，无需编写代码，适合非技术人员或数据探索阶段使用。

- 核心原理：

  - 以「项目」为单位管理数据集，支持导入 CSV/Excel/JSON 等格式；
  - 通过「聚类」「标准化」「转换」功能批量处理脏数据，可视化展示清洗前后的差异。

- 核心功能：

  - 数据去重：基于字符串相似度（如编辑距离、n-gram）聚类去重（如「张三」「张 三」「张三_」合并为统一格式）；
  - 格式标准化：批量修正日期（如「2026.03.15」→「2026-03-15」）、数值（如「1,234 元」→「1234」）格式；
  - 缺失值处理：可视化标记缺失值，支持按列均值 / 中位数 / 自定义规则填充；
  - 文本提取：通过简单正则表达式提取关键信息（如从「手机号：13812345678」中提取手机号）。

- 适配场景：

  - 风控数仓初期的「原始数据探索」（如信贷申请表格的初步清洗）；
  - 非结构化文本数据的快速规整（如用户填写的非标准地址信息）；
  - 团队协作场景（可导出清洗规则，供技术人员复现）。

  

### 2. Pandas（Python 编程式数据清洗）

- **核心定位**：Python 数据处理核心库，通过 DataFrame 结构提供丰富的编程式清洗函数，支持复杂逻辑和自动化流程，是数据工程师的主流选择。

- 核心清洗函数（高频使用）：

  | 函数 / 方法                        | 核心用途              | 风控数仓场景示例                                             |
  | :--------------------------------- | :-------------------- | :----------------------------------------------------------- |
  | `fillna()`                         | 缺失值填充            | `df['amount'].fillna(0)`（金额缺失填 0）                     |
  | `dropna()`                         | 删除缺失值行 / 列     | `df.dropna(subset=['user_id'])`（删除无用户 ID 的行）        |
  | `replace()`                        | 批量替换值 / 正则替换 | `df['status'].replace({'失败':'0','成功':'1'})`              |
  | `astype()`                         | 数据类型转换          | `df['id'].astype('int64')`（ID 转为 BIGINT）                 |
  | `str.extract()`                    | 正则表达式提取        | `df['phone'] = df['info'].str.extract(r'(\d{11})')`（提取手机号） |
  | `duplicated()`/`drop_duplicates()` | 重复值检测 / 删除     | `df.drop_duplicates(subset=['order_id'], keep='first')`（订单号去重） |
  | `apply()`/`map()`                  | 自定义函数清洗        | 用 lambda 函数清洗地址：`df['address'].apply(lambda x: x.strip() if pd.notna(x) else x)` |

- **关键补充**：Pandas 无官方 `dataframe.clean()` 方法，通常通过「函数组合 + 自定义逻辑」实现完整清洗流程，第三方库 `pandas-clean` 可简化基础清洗，但生产环境优先使用原生函数保证稳定性。

## 二、数据清洗工具选型与落地思路

### 1. 工具选型原则（适配风控数仓项目）

| 维度             | OpenRefine                       | Pandas                                           |
| :--------------- | :------------------------------- | :----------------------------------------------- |
| 使用门槛         | 低（可视化操作，无需编程）       | 中（需掌握 Python 基础）                         |
| 复杂逻辑支持     | 弱（仅支持简单正则 / 固定规则）  | 强（支持正则、循环、条件判断等复杂逻辑）         |
| 自动化适配       | 弱（需手动操作，难以集成到 ETL） | 强（可封装为脚本，接入 Airflow 调度）            |
| 数据规模         | 适合小批量（GB 级以下）          | 适合中大规模（10GB 级以内，超大规模需结合 Dask） |
| 风控数仓适配场景 | 原始数据探索、临时清洗           | 生产级 ETL 流程、复杂规则清洗（如正则提取）      |

### 2. 本项目落地方案（SQL 为主 + Python 补充）

#### 核心思路：

风控数仓以 SQL 完成基础清洗（如空值过滤、简单格式转换），将 SQL 难以实现的复杂清洗逻辑（如正则提取、模糊匹配）交给 Python（Pandas）处理，形成「SQL + Python」的分层清洗体系。

#### 步骤 1：SQL 基础清洗（数仓内完成）

```sql
-- 风控ODS层基础清洗（以信贷申请表为例）
SELECT 
    -- 非空过滤+类型转换
    COALESCE(person_id, '') AS person_id,
    CAST(apply_amount AS BIGINT) AS apply_amount,
    -- 简单格式标准化
    REPLACE(apply_time, '/', '-') AS apply_time,
    -- 缺失值填充
    COALESCE(status, 'unknown') AS status
FROM raw_credit_apply
-- 删除关键字段缺失的行
WHERE person_id IS NOT NULL;
```

#### 步骤 2：Python（Pandas）复杂清洗（补充 SQL 短板）

```python
import pandas as pd
import re

# 1. 读取SQL清洗后的基础数据
df = pd.read_sql("SELECT * FROM ods_credit_apply_clean_base", conn)

# 2. 复杂清洗逻辑（SQL难以实现）
## （1）正则提取：从备注字段提取身份证号
df['id_card'] = df['remark'].str.extract(r'(\d{17}[\dXx])')

## （2）模糊去重：基于user_id+手机号去重（处理重复申请）
df = df.drop_duplicates(subset=['user_id', 'phone'], keep='last')

## （3）自定义规则清洗地址（如统一省市区格式）
def clean_address(address):
    if pd.isna(address):
        return '未知地址'
    # 去除特殊字符，统一省名格式
    address = re.sub(r'[^\u4e00-\u9fa50-9]', '', address)
    address = address.replace('四川省', '四川').replace('成都市', '成都')
    return address

df['clean_address'] = df['address'].apply(clean_address)

# 3. 将清洗后的数据写入数仓DWD层
df.to_sql('dwd_credit_apply', con=conn, if_exists='append', index=False)
```

#### 步骤 3：OpenRefine 辅助使用（探索阶段）

- 场景：拿到新的原始信贷数据时，先用 OpenRefine 做「探索性清洗」：
  1. 导入数据，通过「Facets」功能查看各字段的缺失值、异常值分布；
  2. 对非标准字段（如用户职业「自由职业」「自由职业者」「自雇」）做聚类合并；
  3. 导出清洗规则（如正则表达式），交给 Python 脚本复现，保证流程自动化。

## 四、实操避坑要点

1. OpenRefine 避坑：

   - 避免直接将 OpenRefine 清洗结果用于生产（无版本控制），需将操作转换为 Python 脚本；
   - 处理中文数据时，选择「Chinese (Unicode)」分词器，提升聚类去重准确率。

2. Pandas 避坑：

   - 处理大文件时，使用 `chunksize` 分块读取（如 `pd.read_csv(file, chunksize=10000)`），避免内存溢出；
   - 正则提取时添加异常处理，避免因无匹配值导致列值全为 NaN；
   - 数据类型转换前先校验（如 `pd.to_numeric(df['amount'], errors='coerce')`），避免转换失败中断流程。

3. SQL + Python 协同避坑：

   - 基础清洗（去重、空值过滤）优先用 SQL 完成（数仓引擎效率更高），复杂逻辑再用 Python；
   - 清洗后需增加「数据校验」步骤（如检查清洗后 ID 唯一性、金额非负），确保数据质量。

   

## 五、总结

1. 数据清洗的核心目标是「将脏数据转换为结构化、标准化的数据」，适配风控数仓的审计和分析需求；

3. 掌握 Pandas 核心清洗函数（fillna、replace、str.extract）和正则表达式，是数据工程师处理复杂清洗场景的核心能力，适配成都金融 / 数仓类岗位需求。
