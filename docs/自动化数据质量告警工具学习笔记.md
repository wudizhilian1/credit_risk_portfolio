# 自动化数据质量告警工具学习笔记
## 一、核心工具认知
### 1. Prometheus + Alertmanager 基本架构
- **Prometheus**：时序数据库 + 指标采集引擎，负责定时拉取、存储各类监控指标（数值型时间序列）。
- **Alertmanager**：接收 Prometheus 触发的告警，进行**去重、分组、抑制、路由**，最终发送到邮件、钉钉、企业微信、飞书等渠道。

### 2. 在数据领域的典型应用
- 数仓任务运行状态监控（成功/失败、耗时、延迟）
- 数据质量指标监控（空值率、重复率、通过率、对账差异）
- 数据产出及时性监控（分区是否按时生成）
- 资源监控（CPU、内存、数据量突增突减）

### 3. 工作流程
1. **暴露指标**：数据脚本 / 调度系统将监控结果以指标形式暴露（HTTP 接口）。
2. **采集指标**：Prometheus 定时拉取指标。
3. **配置告警规则**：设置阈值（如空值率 > 0 则告警）。
4. **触发告警**：满足条件后发送给 Alertmanager。
5. **分发告警**：Alertmanager 按配置发送通知。

## 三、核心概念（数据领域视角）
### 1. Metric 指标类型
- **Gauge**：仪表盘类型，可升可降（适合：空值率、通过率、金额差异、行数波动）。
- **Counter**：只增不减（适合：失败次数、异常条数）。

### 2. 关键能力
- **多维度标签**：`table="dws_channel_daily", rule="null_rate"`。
- **告警分组**：同一批表同时异常时合并为一条通知。
- **告警抑制**：避免上游报错引发下游大量重复告警。
- **静默与屏蔽**：维护期临时关闭告警。

## 四、落地思路：用 prometheus_client 暴露指标
### 1. 实现路径
1. 在 Python 数据质量脚本中引入 `prometheus_client`。
2. 将监控结果（空值率、差异值、通过率等）暴露为 Gauge 指标。
3. 启动一个简易 HTTP Server 供 Prometheus 拉取。
4. Prometheus 配置抓取任务。
5. 编写告警规则规则，接入 Alertmanager 发送通知。

### 2. 简单示例结构（伪代码）
```python
from prometheus_client import Gauge, start_http_server

# 定义指标
dq_null_rate = Gauge("dq_null_rate", "表字段空值率", ["table", "field"])
dq_reconcile_diff = Gauge("dq_reconcile_diff", "ADS与DWS对账差异", ["table"])

# 监控结果写入指标
dq_null_rate.labels(table="dws_strategy_daily", field="strategy_name").set(0.05)
dq_reconcile_diff.labels(table="ads_overview_daily").set(12)

# 暴露端口
start_http_server(8000)
```

### 3. Prometheus 告警规则示例
```yaml
groups:
- name: dataQualityRules
  rules:
  - alert: HighNullRate
    expr: dq_null_rate > 0
    for: 1m
    labels:
      severity: error
    annotations:
      summary: "字段空值率过高"
      description: "表={{ $labels.table }} 字段={{ $labels.field }} 空值率={{ $value }}"
```

## 六、总结
- Prometheus 负责**指标采集 + 存储 + 告警判断**。
- Alertmanager 负责**告警分发、降噪、路由**。
- 数据质量监控非常适合接入该体系，将业务指标标准化、可视化、企业级告警化。
