# Week 3 项目总结（Day 15-21）

## 本周完成工作
- 搭建作品集项目骨架，完成 Git 初始化。
- 设计并创建 ODS 层事实表（申请、决策）及四张维度表（渠道、客户、策略、拒绝原因）。
- 构建 DWD 层明细表，实现按时间戳去重取最新记录。
- 增强维表属性，加入渠道分组、客户信用分、策略类型等字段。
- 定义风控核心指标口径，编写 SQL 计算申请量、通过率、拒绝率等。
- 扩展模拟数据至30天，并引入4类异常场景（申请突增、渠道缺失、通过率骤降、金额异常）。
- 编写一键验证脚本，确保所有表和数据正常。

## 遇到的问题与解决方案
1. **DuckDB 分区表语法不支持**：原计划使用 `PARTITION BY`，但 DuckDB 表级分区需通过目录结构实现，因此改为在查询时利用 `dt` 列过滤，数据源已分区。
2. **维表新增字段类型冲突**：使用 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` 避免重复执行报错。
3. **异常金额验证**：生成数据时部分金额为负数，后续需在 DQ 监控中捕获。
