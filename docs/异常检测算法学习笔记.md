# 异常检测算法学习笔记

## 一、核心算法概述

### 1. Isolation Forest（孤立森林）

- **核心原理**：通过随机选择特征、随机选择分割值的方式递归切割特征空间，异常点由于特征偏离正常样本，会被更快孤立（切割次数更少），因此可通过 “孤立路径长度” 判断样本是否为异常。
- 核心优势：
  - 适合**高维数据**（如风控场景中的多维度用户特征、交易特征），计算效率高，无需计算样本间距离；
  - 对异常点比例不敏感，无需标注数据（无监督学习）；
  - 训练和推理速度快，适配实时检测场景。
- 风控场景应用：
  - 实时检测异常交易（如信用卡盗刷、大额异常转账）；
  - 信贷申请异常检测（如申请人信息伪造、多头借贷特征异常）。

### 2. One-Class SVM（单类支持向量机）

- **核心原理**：在无监督场景下，学习正常样本的特征边界，将特征空间中落在边界外的样本判定为异常点；核心是找到一个超平面，最大化正常样本到超平面的距离。
- 核心特点：
  - 适合低 / 中维数据，对非线性特征空间拟合能力强；
  - 对异常点比例敏感，样本量较大时计算成本高；
  - 需手动调参（如核函数、惩罚系数），适配不同场景。
- 风控场景应用：
  - 小额交易异常检测（特征维度低、样本量适中）；
  - 客户行为基线建模（如识别偏离日常行为的操作）。

## 二、风控场景落地要点

1. 实时性适配：
   - Isolation Forest 推理速度快，可集成到风控实时决策引擎，用于交易 / 申请的毫秒级异常判定；
   - One-Class SVM 适合离线批量检测（如每日账户行为异常复盘）。
2. 数据适配：
   - 需对风控数据做预处理（如缺失值填充、特征标准化），避免高维稀疏特征影响算法效果；
   - 可结合业务规则（如地域、时间、金额阈值）过滤噪声，提升算法精度。
3. 后续实践计划：

   - 输出异常检测结果可视化报告（如异常样本分布、检测准确率）。
