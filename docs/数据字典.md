# 数据字典和数据结构

本文档定义了信贷风控数仓项目中各表的字段含义、数据类型及口径说明。  
表分为两类：

- **ODS 层**：原始数据接入层，保留业务系统最细粒度记录。
- **维度表**：描述业务实体（如渠道、客户、策略、拒绝原因）的静态信息。

## ODS 层事实表

### ods_apply – 申请事实表
| 字段名      | 数据类型      | 可为空 | 主键/分区 | 描述                                         |
| ----------- | ------------- | ------ | --------- | -------------------------------------------- |
| apply_id    | VARCHAR       | NO     | 主键      | 申请单唯一标识，关联 `ods_decision.apply_id` |
| user_id     | VARCHAR       | NO     |           | 用户ID，关联 `dim_customer.user_id`          |
| channel_id  | VARCHAR       | YES    |           | 渠道ID，关联 `dim_channel.channel_id`        |
| amount      | DECIMAL(18,2) | YES    |           | 申请金额，单位元                             |
| apply_time  | TIMESTAMP     | YES    |           | 申请时间戳                                   |
| update_time | TIMESTAMP     | YES    |           | 记录更新时间（通常与 `apply_time` 相同）     |
| dt          | DATE          | NO     | 分区      | 分区日期，取自申请时间（事件日）             |

### ods_decision – 决策事实表
| 字段名           | 数据类型  | 可为空 | 主键/分区 | 描述                                                         |
| ---------------- | --------- | ------ | --------- | ------------------------------------------------------------ |
| apply_id         | VARCHAR   | NO     | 主键      | 申请单ID，关联 `ods_apply.apply_id`                          |
| decision         | VARCHAR   | YES    |           | 决策结果：`PASS`（通过）、`REJECT`（拒绝）、`REVIEW`（人工审核） |
| reject_reason    | VARCHAR   | YES    |           | 拒绝原因代码，仅当 `decision='REJECT'` 时有值，关联 `dim_reject_reason.reason_code` |
| strategy_version | VARCHAR   | YES    |           | 策略版本号，关联 `dim_strategy.strategy_version`             |
| decision_time    | TIMESTAMP | YES    |           | 决策时间戳                                                   |
| dt               | DATE      | NO     | 分区      | 分区日期，取自决策时间（事件日）                             |

## 维度表

### dim_channel – 渠道维度表
| 字段名        | 数据类型 | 可为空 | 主键 | 描述                                   |
| ------------- | -------- | ------ | ---- | -------------------------------------- |
| channel_id    | VARCHAR  | NO     | 主键 | 渠道唯一标识，如 `APP`、`WEB`          |
| channel_name  | VARCHAR  | YES    |      | 渠道名称，如“手机应用”                 |
| channel_type  | VARCHAR  | YES    |      | 渠道类型：`APP` / `WEB` / `H5` / `API` |
| is_active     | BOOLEAN  | YES    |      | 是否有效，默认为 `true`                |
| channel_group | VARCHAR  | YES    |      | 渠道分组                               |
| priority      | INT      | YES    |      | 优先级                                 |

### dim_customer – 客户维度表
| 字段名            | 数据类型 | 可为空 | 主键 | 描述                                |
| ----------------- | -------- | ------ | ---- | ----------------------------------- |
| user_id           | VARCHAR  | NO     | 主键 | 用户唯一标识                        |
| user_name         | VARCHAR  | YES    |      | 用户姓名（模拟）                    |
| age               | INT      | YES    |      | 年龄                                |
| registration_date | DATE     | YES    |      | 注册日期                            |
| risk_level        | VARCHAR  | YES    |      | 风险等级：`LOW` / `MEDIUM` / `HIGH` |
| gender            | VARCHAR  | YES    |      | 性别                                |
| city              | VARCHAR  | YES    |      | 城市                                |
| credit_score      | INT      | YES    |      | 信用分（模拟）                      |

### dim_strategy – 策略维度表
| 字段名           | 数据类型 | 可为空 | 主键 | 描述                               |
| ---------------- | -------- | ------ | ---- | ---------------------------------- |
| strategy_version | VARCHAR  | NO     | 主键 | 策略版本号，如 `v1.0`              |
| strategy_name    | VARCHAR  | YES    |      | 策略名称                           |
| effective_date   | DATE     | YES    |      | 生效日期                           |
| expiry_date      | DATE     | YES    |      | 失效日期，若为 `NULL` 表示永久有效 |
| description      | VARCHAR  | YES    |      | 策略描述                           |
| strategy_type    | VARCHAR  | YES    |      | 策略类型：准入/反欺诈/额度         |
| owner_team       | VARCHAR  | YES    |      | 所属团队                           |

### dim_reject_reason – 拒绝原因维度表
| 字段名          | 数据类型 | 可为空 | 主键 | 描述                                      |
| --------------- | -------- | ------ | ---- | ----------------------------------------- |
| reason_code     | VARCHAR  | NO     | 主键 | 拒绝原因代码，如 `FRAUD`                  |
| reason_desc     | VARCHAR  | YES    |      | 原因描述，如“欺诈风险”                    |
| risk_level      | VARCHAR  | YES    |      | 关联的风险等级：`LOW` / `MEDIUM` / `HIGH` |
| reason_category | VARCHAR  | YES    |      | 原因类别                                  |

## 附注
- 所有表均存储在 DuckDB 数据库 `dev.duckdb` 中。
- 本字典可通过查询 `information_schema.columns` 动态生成，此处为静态版本。
- 字段描述基于业务含义，与实际数据保持一致。
