# AutoML 工具（H2O.ai/TPOT）学习笔记

## 一、AutoML 核心概述

### 1. 定义与价值

AutoML（自动化机器学习）是一类能够**自动化完成机器学习建模全流程**的工具 / 框架，核心覆盖：数据预处理、特征工程、模型选择与调参、模型评估、模型部署等环节，无需人工逐一步骤干预。

在风控场景中，AutoML 可快速搭建**基线模型**（如信用评分、逾期预测、欺诈识别模型），大幅降低建模门槛、缩短模型开发周期，也可作为人工调优的参考基准。

### 2. 核心优势（对比传统手动建模）

| 维度     | 传统手动建模                 | AutoML 工具                       |
| :------- | :--------------------------- | :-------------------------------- |
| 效率     | 需数天 / 周完成全流程        | 小时级 / 分钟级生成可用模型       |
| 门槛     | 需深厚算法与调参经验         | 低代码 / 无代码，业务人员也能使用 |
| 覆盖度   | 仅尝试少数熟悉的模型         | 自动遍历数十种模型 + 超参组合     |
| 一致性   | 易受人工经验影响，结果不稳定 | 标准化流程，结果可复现            |
| 落地成本 | 高（需算法工程师全流程参与） | 低（自动化降低人力投入）          |

## 二、主流 AutoML 工具详解

### 1. H2O.ai

- **定位**：开源企业级 AutoML 平台，支持分布式计算，适配大规模数据场景（风控核心首选）。

- 核心原理

  ：

  - 内置多种经典机器学习模型（GBM、XGBoost、LightGBM、随机森林、神经网络等）；
  - 自动化流程：数据清洗 → 特征选择 → 模型训练与超参数调优（网格搜索 / 随机搜索）→ 模型融合 → 生成评估报告；
  - 支持分类、回归、异常检测等风控高频任务，可输出可解释性报告（SHAP/LIME），满足风控合规要求。

  

- 风控场景适配

  ：

  - 快速构建逾期预测、欺诈识别基线模型；
  - 支持千万级样本的分布式训练，适配风控海量数据；
  - 输出模型评估指标（AUC、KS、精准率 / 召回率），贴合风控模型评估标准。

  

- 使用特点

  ：

  - 提供 Python/R API、Web UI 两种使用方式，新手友好；
  - 支持模型导出为 PMML/MOJO 格式，便于生产环境部署。

  

### 2. TPOT

- **定位**：基于 Python 的开源 AutoML 工具，以「遗传算法」为核心，适配中小规模数据的建模场景。

- 核心原理

  ：

  - 基于 scikit-learn 生态，通过遗传算法自动搜索最优的「数据预处理 + 特征工程 + 模型」组合；
  - 流程：定义搜索空间（如标准化、PCA、随机森林、SVM 等）→ 遗传算法迭代筛选最优 pipeline → 输出最终模型代码；
  - 全程生成可解释的 Python 代码，便于人工二次优化。

  

- 风控场景适配

  ：

  - 适用于小样本风控场景（如细分客群的风险预测）；
  - 生成的代码可直接修改，便于融入人工风控规则；
  - 轻量化部署，适合快速验证风控特征有效性。

  

- 使用特点

  ：

  - 纯代码驱动，需基础 Python 能力；
  - 搜索过程耗时较长（遗传算法迭代），适合非实时的基线模型构建。

  

## 三、AutoML 工具在风控中的落地建议

### 1. 短期落地

- 用 H2O.ai 对风控核心数据集（如用户行为、信贷数据）快速构建基线模型，获取基础评估指标（AUC/KS）；
- 用 TPOT 验证特征组合的有效性，生成初始建模代码，减少手动编写 pipeline 的工作量。

### 2. 长期优化

- 将 AutoML 生成的基线模型与人工调优模型融合，提升风控模型效果；
- 结合风控业务规则，对 AutoML 输出的模型进行可解释性增强，满足监管要求；
- 集成到风控建模流程中，作为模型迭代的快速验证环节。

## 四、核心总结

1. AutoML 核心价值是**自动化建模全流程**，在风控中可快速搭建基线模型，降低建模门槛、缩短开发周期；
2. H2O.ai 适配大规模、企业级风控场景，支持分布式训练与合规性解释；TPOT 适配中小规模数据，生成可修改的建模代码；
3. 落地优先级：先用 H2O.ai 构建风控基线模型，再基于 TPOT 验证特征 / 流程优化方向，最终结合人工调优提升模型效果。
