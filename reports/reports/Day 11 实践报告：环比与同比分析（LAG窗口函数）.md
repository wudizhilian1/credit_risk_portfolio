## 1. 练习目标

- 掌握使用 `LAG` 窗口函数获取前 N 行的值，计算指标变化率。
- 处理边界情况（缺失日期、除零、空值），明确口径。
- 结合风控指标（申请量）进行实际计算，并用日历表处理日期不连续问题。

### 3.2 每日申请量及环比增长率

```sql
WITH daily_apply AS (
    SELECT 
        dt,
        COUNT(DISTINCT apply_id) as apply_cnt
        FROM v_apply
        where dt between '2024-01-01' and '2024-01-10'
        GROUP BY dt
)
SELECT 
    dt,
    apply_cnt,
    LAG(apply_cnt) OVER (ORDER BY dt) as prev_apply_cnt,
    CASE 
        WHEN LAG(apply_cnt) OVER (ORDER BY dt) IS NULL OR LAG(apply_cnt) OVER (ORDER BY dt) = 0 THEN NULL
        ELSE ROUND(100.0 * (apply_cnt - LAG(apply_cnt) OVER (ORDER BY dt)) / LAG(apply_cnt) OVER (order by dt), 2)
        END AS mom_growth_pct
    FROM daily_apply
    ORDER BY dt
```

### 3.4 结合风控指标（通过率环比）

```sql
WITH daily_metrics AS (
    SELECT
        a.dt,
        COUNT(DISTINCT a.apply_id) AS apply_cnt,
        COUNT(DISTINCT d.apply_id) AS decision_cnt,
        COUNT(DISTINCT CASE WHEN d.decision = 'PASS' THEN d.apply_id END) AS pass_cnt
    FROM v_apply a
    LEFT JOIN v_decision d ON a.apply_id = d.apply_id AND d.dt = a.dt
    WHERE a.dt BETWEEN '2024-01-01' AND '2024-01-10'
    GROUP BY a.dt
)
SELECT
    dt,
    apply_cnt,
    pass_cnt,
    ROUND(100.0 * pass_cnt / NULLIF(apply_cnt, 0), 2) AS pass_rate,
    LAG(ROUND(100.0 * pass_cnt / NULLIF(apply_cnt, 0), 2)) OVER (ORDER BY dt) AS prev_pass_rate,
    ROUND(
        100.0 * (
            ROUND(100.0 * pass_cnt / NULLIF(apply_cnt, 0), 2) 
            - LAG(ROUND(100.0 * pass_cnt / NULLIF(apply_cnt, 0), 2)) OVER (ORDER BY dt)
        ) / NULLIF(LAG(ROUND(100.0 * pass_cnt / NULLIF(apply_cnt, 0), 2)) OVER (ORDER BY dt), 0),
        2
    ) AS pass_rate_mom_pct
FROM daily_metrics
ORDER BY dt;
```

## LAG()函数

### 一、LAG () 函数核心定义

`LAG()` 是**窗口函数（Window Function）**，作用是：

在不使用自连接的情况下，**获取当前行之前第 N 行的数据**（可以理解为 “向前看 N 行”）。

#### 1. 基础语法

```sql
LAG(列名, 偏移量, 默认值) OVER (
    PARTITION BY 分组列  -- 可选，按某列分组
    ORDER BY 排序列     -- 必选，定义“前后”顺序
)
```

- **偏移量**：默认 1（向前看 1 行），比如写 2 就是向前看 2 行；
- **默认值**：可选，当向前看没有数据时返回的值（默认 NULL）；
- **核心**：`ORDER BY` 必须有，否则 “前后” 无意义；`PARTITION BY` 用于分组内计算（比如按用户、按机构）。

#### 2. 一句话理解

比如查用户的信贷记录，用 `LAG(还款金额) OVER (PARTITION BY 用户ID ORDER BY 还款日期)`，就能直接拿到 “该用户上一次的还款金额”。

### 三、关键注意事项（避坑）

1. **必须加 ORDER BY**：没有排序的 “前后” 无意义，比如按时间、按交易序号排序是核心；
2. **PARTITION BY 分组**：如果不加，会对全表所有行统一 “向前看”，比如会把用户 A 的记录和用户 B 的混在一起；
3. **NULL 处理**：第一行没有 “前一行”，默认返回 NULL，建议加默认值（比如 0）避免后续计算报错；
4. **与 LEAD () 对比**：`LAG()` 是 “向前看”，`LEAD()` 是 “向后看”，风控中 `LAG()` 更常用。

------

### 总结

1. `LAG()` 是 SQL 窗口函数，核心是**分组内向前取第 N 行数据**，无需自连接，效率远高于关联查询；
2. 风控中主要用于**计算时序间隔、识别连续行为、提取历史特征**，是时序特征工程的标配；
3. 使用关键：必加 `ORDER BY` 定义顺序，按需加 `PARTITION BY` 分组，注意 NULL 值处理。

## 4. 口径与边界说明

| 口径要素       | 说明                                                         |
| :------------- | :----------------------------------------------------------- |
| **指标定义**   | 环比：当前日指标与前一日对比；同比：当前日指标与7天前同日对比。 |
| **LAG偏移量**  | 环比使用 `LAG(..., 1)`，同比使用 `LAG(..., 7)`。需保证数据按日期排序。 |
| **空值处理**   | 当 N 天前无数据时，`LAG` 返回 NULL，对应增长率设为 NULL。    |
| **除零保护**   | 前值为 0 时，增长率返回 NULL，避免除零错误。                 |
| **日期连续性** | 使用日历表左连接聚合结果，缺失日期填充 0，确保 LAG 按正确的日期偏移取值。 |
| **分母选择**   | 增长率公式：(当前值 - 前值) / 前值 * 100。前值为 0 时无定义。 |

## 5. 性能点

- **先聚合后窗口**：在 `daily_apply` CTE 中先按天聚合，再对少量结果使用 LAG，避免在明细级使用窗口函数。
- **分区裁剪**：在 `v_apply` 查询中使用 `dt BETWEEN` 过滤，确保只扫描所需分区（通过 `EXPLAIN` 可验证）。
- **列裁剪**：聚合时只取 `apply_id` 和 `dt`，无需其他字段。
- **日历表生成**：使用 `range` 表函数高效生成连续日期，避免手动构造。

# 异常检测：移动平均法 & 3σ 法在风控指标监控中的应用

## 一、移动平均法（MA）原理

### 1. 核心思想

通过**历史窗口内数据的平均值**构建**动态基准**，用来平滑噪声、刻画正常趋势，当前值与基准偏离过大则判定为异常。

### 2. 常用方法

- **简单移动平均 SMA**
  $$
  SMA_t = \frac{x_{t-n} + x_{t-n+1} + \dots + x_{t-1}}{n}
  $$
  

  - n：窗口大小（常用 7/14/30 天）
  - 适用于平稳、无剧烈趋势的指标

  

- **指数移动平均 EMA**
  $$
  EMA_t = \alpha \cdot x_t + (1-\alpha) \cdot EMA_{t-1}
  $$
  

  - α：平滑系数（0<α<1，越近数据权重越高）
  - 对突变、趋势变化更敏感，适合风控实时监控

  

------

## 二、3σ 法（3‑sigma 原则）原理

### 1. 核心假设

指标在正常情况下**近似服从正态分布**。

### 2. 判定规则

- 计算窗口内均值 μ、标准差 σ

- 正常区间：

  [μ−3σ, μ+3σ]

- 超出该区间：概率 < 0.3%，视为**统计异常**

### 3. 与移动平均结合（风控标准方案）

- 动态均值 μ = 移动平均（SMA/EMA）
- 动态波动 σ = 滚动窗口标准差
- 得到**自适应动态异常区间**，而非固定阈值

------

## 三、移动平均 + 3σ 风控监控流程

1. 选定监控指标：日拒贷率、逾期率、审批量、规则触发量、渠道通过率等

2. 设定滚动窗口：如近 14 天或 30 天

3. 计算滚动均值 μ、滚动标准差 σ

4. 计算动态上下限：
   $$
   {upper} = \mu + 3\sigma,\quad \text{lower} = \mu - 3\sigma
   $$

5. 当日指标超出区间 → 触发异常告警

------

## 四、结合环比 / 同比设置告警规则（降低误报）

### 1. 环比（相邻周期对比）

- 公式：
  $$
  {环比波动} = \frac{\text{当日值} - \text{昨日/上周同日值}}{\text{昨日/上周同日值}}
  $$

- 用途：捕捉**突发暴涨 / 暴跌**（集中欺诈、系统故障、规则漂移）

- 常用阈值：±20%～±50%（按业务调整）

### 2. 同比（历史同期对比）

- 公式：
  $$
  {同比波动} = \frac{\text{当日值} - \text{上周同日/上月同日值}}{\text{上周同日/上月同日值}}
  $$

- 用途：消除**周内周期、节假日、时段效应**

- 常用阈值：±30%～±60%

### 3. 风控组合告警策略（推荐）

满足任一条件即告警：

1. 指标超出 **滚动 3σ 区间**
2. **环比波动 ≥ 阈值**
3. **同比波动 ≥ 阈值**
4. 连续 2 天偏离均值 → 趋势性异常告警

------

## 五、在风控中的典型用途

- 监控**模型 / 规则稳定性**（PSI、拒贷率、通过率漂移）
- 发现**集中欺诈、批量攻击、黄牛进件**
- 监控**渠道质量突变**（某渠道通过率 / 逾期率异常）
- 监控**系统异常**（进件量、审批量突降为 0）
- 早期预警**逾期爆发、资产质量恶化**

------

## 六、总结（可直接背诵）

1. **移动平均**：提供**动态正常基准**，平滑噪声与周期
2. **3σ 原则**：提供**统计意义上的异常边界**
3. **移动平均 + 3σ**：自适应、鲁棒的时间序列异常检测
4. **+ 环比 / 同比**：大幅降低周期性误报，适合真实风控场景
5. 整体是**风控指标监控、模型监控、异常预警**的**基础标配算法**
