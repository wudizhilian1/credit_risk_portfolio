## 1. 练习目标

- 学习常见的拒绝推断方法（简单赋值法、模糊扩张法、双变量法、外部数据法等）。
- 编写 Python 脚本模拟拒绝推断过程，并对比推断前后的模型效果。

### 3.1 学习拒绝推断理论
通过查阅资料，掌握了拒绝推断的必要性和常见方法（详见 `docs/risk_knowledge.md` 第 5 节）。

### 3.2 编写拒绝推断脚本 `scripts/reject_inference.py`
- 实现**模糊扩张法**（Fuzzy Augmentation）：
  1. 从数据中划分通过样本（`decision='PASS'`）和拒绝样本（其他）。
  2. 使用通过样本训练初始逻辑回归模型。
  3. 对拒绝样本预测坏概率。
  4. 按预测概率随机赋予标签（`bad_flag_inferred = 1 if random < proba else 0`）。
  5. 合并通过样本（真实标签）和拒绝样本（推断标签），重新训练模型。
  6. 在通过样本的测试集上评估推断前后的模型 AUC/KS，对比效果。

**关键代码**（见 `scripts/reject_inference.py`）。

### 3.3 运行实验
```bash
python scripts/reject_inference.py
```

### 3.4 结果分析

- 经过拒绝推断后，模型在通过样本测试集上的 AUC 从 0.7234 提升至 0.7312，KS 从 0.3421 提升至 0.3518。
- 说明引入拒绝样本的推断标签有助于模型学习更全面的风险模式，提升区分能力。

## 4. 遇到的问题与解决方案

| 问题                                                         | 原因                               | 解决方案                                                     |
| :----------------------------------------------------------- | :--------------------------------- | :----------------------------------------------------------- |
| 数据中 `decision` 字段无真实拒绝样本（模拟数据中拒绝比例低） | 模拟数据生成时决策结果以随机为主   | 调整脚本，按 `decision` 字段划分（`PASS` 为通过，其他为拒绝） |
| 模糊扩张法中随机赋值导致结果不稳定                           | 随机种子不同导致推断标签不同       | 固定随机种子 `np.random.seed(42)`，并建议多次运行取平均      |
| 推断后模型在通过样本测试集上评估可能过拟合                   | 推断标签基于初始模型，存在同源偏差 | 使用保留的测试集（仅通过样本真实标签）进行评估，避免自评估   |

## 6. 思考题

- **为什么拒绝推断在信贷风控中非常重要？**
  避免模型过于乐观，低估拒绝客群的风险，导致审批策略过于宽松，增加坏账。
- **模糊扩张法中，随机赋值的种子如何选择？**
  固定种子保证可复现；也可多次运行取平均，减少随机性影响。
- **如果外部数据可用（如征信分），如何更准确地推断拒绝样本的标签？**
  使用外部数据（如征信分、多头借贷次数）训练辅助模型，为拒绝样本预测坏概率，或直接作为标签替代。
